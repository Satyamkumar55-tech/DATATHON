# 🚀 DATATHON – AutoInsight

## 📌 About the Project

**AutoInsight** is an intelligent data analysis and visualization application built during **DATATHON 2026**.

The goal of the project is to make data analysis easier and more accessible. Users can upload a CSV dataset, clean and analyze the data, explore patterns, visualize insights, and get an overall understanding of their dataset through an interactive dashboard.

Built under a tight **6-hour Datathon**, the project focuses on transforming raw data into meaningful insights quickly and efficiently.

---

## ✨ Features

- 📂 Upload and analyze CSV datasets
- 🧹 Automated data cleaning
- 📊 Interactive data analysis and visualization
- 🔍 Automated data insights
- 📈 Data quality score
- 🧩 Data clustering and pattern detection
- 🎙️ Voice summary of insights
- 📱 User-friendly dashboard interface

🚀 How It Works
Upload a CSV dataset.
The application processes and analyzes the dataset.
Data cleaning and preprocessing are performed.
The system generates useful insights and statistics.
Users can explore visualizations and patterns in the data.
Additional features such as clustering and data quality analysis help provide deeper insights.
